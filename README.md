# chat-ui-with-audit-trail

This project continues as **quarkus-chat-ui 3.x** at
[https://github.com/scivicslab/quarkus-chat-ui](https://github.com/scivicslab/quarkus-chat-ui).

The whole history of this repository, its `main` branch included, is merged into quarkus-chat-ui's
`main`, and its releases are there under the tags `audit-trail-v1.0.0` to `audit-trail-v2.2.0`.
The Maven coordinates changed with the move: the group id is `com.scivicslab.chatui`, the body is
`quarkus-chat-ui` and the plugins are `quarkus-chat-ui-plugin-*`. New work goes to quarkus-chat-ui;
this repository is no longer developed.
